# AISANCE — лендинг

Статичный сайт: HTML + CSS + минимум JS. Без сборки, без зависимостей, без фреймворков.
Папка `output/` — это уже готовый к публикации корень сайта.

---

## 1. Что нужно сделать перед публикацией (обязательно)

**Ссылка на Telegram.** В коде стоит заглушка `https://t.me/CHANGE_ME` в трёх местах
(шапка, финальный блок «Начало», футер). Замените на реальный адрес:

```bash
cd output && sed -i '' 's|https://t.me/CHANGE_ME|https://t.me/ВАШ_НИК|g' index.html
```

Все три места помечены в `index.html` комментарием `<!-- ЗАМЕНИТЬ: рабочая ссылка на Telegram -->`.

Всё остальное — рабочее и готовое: логотип, favicon, OG-превью, SEO-теги, robots, sitemap,
ссылка на личный кабинет `https://app.aisance.space`.

## 2. Публикация

### Netlify (drag & drop, быстрее всего)
1. netlify.com → Sites → **Add new site → Deploy manually**.
2. Перетащить папку `output` целиком в окно браузера.
3. Сайт поднимется на адресе вида `random-name.netlify.app`.

Файл `netlify.toml` уже лежит внутри — заголовки безопасности и кэширование применятся сами.

### Netlify через Git
Залить содержимое `output/` в репозиторий, подключить его в Netlify.
Build command оставить пустым, publish directory — `.` (или `output`, если репозиторий шире).

### Vercel
`vercel --prod` из папки `output`, либо импорт репозитория в дашборде.
Framework preset — **Other**, build command пустой, output directory — `.`.
Настройки в `vercel.json` подхватятся автоматически.

## 3. Домен aisance.space

### Netlify
1. Site → **Domain management → Add a domain** → `aisance.space`.
2. У регистратора домена прописать DNS-записи:

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | `75.2.60.5` |
| CNAME | `www` | `<ваш-сайт>.netlify.app` |

3. HTTPS-сертификат Netlify выпустит сам (Let's Encrypt), обычно в течение часа после
   распространения DNS.

### Vercel
1. Project → **Settings → Domains** → добавить `aisance.space`.
2. DNS-записи:

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | `76.76.21.21` |
| CNAME | `www` | `cname.vercel-dns.com` |

Актуальные значения всегда показывает сама панель хостинга при добавлении домена —
если они отличаются от таблицы, доверяйте панели.

### Личный кабинет
`app.aisance.space` — отдельный проект. Для него у регистратора нужна своя запись
(`CNAME app → адрес того проекта`). Лендинг на неё не влияет и ничего не занимает.

## 4. Структура

```
output/
├── index.html                     единственная страница
├── favicon.ico
├── robots.txt
├── sitemap.xml
├── netlify.toml                   заголовки и кэш для Netlify
├── vercel.json                    то же для Vercel
└── assets/
    ├── css/style.css
    ├── js/main.js                 прогресс, появление блоков, отрисовка линий
    └── img/
        ├── aisance-wordmark-cream.png   логотип для тёмного фона (прозрачный)
        ├── aisance-wordmark-ink.png     логотип для светлого фона (прозрачный)
        ├── og-image.jpg                 превью для мессенджеров, 1200×630
        ├── favicon-16/32/192/512.png
        ├── apple-touch-icon.png
        └── source/                      исходные PNG логотипа, как были переданы
```

Логотип не перерисовывался. Из исходных файлов аккуратно снят сплошной фон
(извлечение по маске яркости), пропорции и форма букв сохранены пиксель в пиксель.
Favicon — фрагмент того же файла: первая «A» с фирменным росчерком, без дорисовки.

## 5. Что где править

| Что | Где |
|---|---|
| Цены (7 000 / 70 000 ₽) | `index.html`, блок `<section id="terms">` + JSON-LD внизу файла |
| Тексты разделов | `index.html`, секции `id="compensation" … id="start"` |
| Цвета, типографика, ритм | `assets/css/style.css`, блок `:root` в самом начале |
| Порядок и состав разделов | `index.html` + список в `<nav class="rail">` |
| SEO, OG-превью | `<head>` в `index.html` |

Разделы пронумерованы римскими цифрами (I–IX) и продублированы в боковом рельсе.
Если удаляете или добавляете секцию — поправьте и `<nav class="rail">`, и `sec__num`.

## 6. Технические заметки

- **Шрифты.** Jost и Inter подключены как в бренд-системе. Fraunces тоже подключён,
  но **в нём нет кириллицы** (Google Fonts отдаёт только latin / latin-ext / vietnamese),
  поэтому русский текст в крупных смысловых акцентах набирается Cormorant Garamond
  300 italic — светлым контрастным курсивом того же характера. Порядок в стеке:
  `'Fraunces', 'Cormorant Garamond', Georgia, serif` — латиница остаётся в Fraunces.
  Если позже появится кириллическая версия Fraunces, достаточно убрать Cormorant
  из переменной `--f-accent`.
- **Мотив линии.** Один и тот же росчерк работает как: подчёркивание в hero,
  разделитель между секциями (`.thread`), схема расхождения боли и причины (`.diverge`),
  ось последовательности метода (`.seq`), полоса прогресса чтения и заполнение бокового рельса.
- **Анимации.** Всё построено на `IntersectionObserver` + CSS-переходах.
  При `prefers-reduced-motion: reduce` движение отключается, контент показывается сразу.
  Без JavaScript страница тоже полностью читается (`<noscript>`-стили в `<head>`).
- **Мобильная версия.** Не уменьшенный десктоп: горизонтальные схемы (расхождение,
  последовательность метода) разворачиваются в вертикальные цепочки, боковой рельс
  заменяется полосой прогресса сверху.
